# Coin Rush

A 2D platformer built with Unity 6.3 LTS and C#. Collect every coin before the timer runs out, stomp enemies, and beat your best score.

![Gameplay](preview.gif)

## Controls
| Key | Action |
|---|---|
| A / D or Arrow keys | Move |
| Space (hold for higher jump) | Jump |
| R | Restart after game over |

## Features
- Responsive platforming: coyote time, jump buffering, variable jump height
- Enemy patrol AI with stomp mechanic
- Animated HUD: score pop, health hearts, color-changing timer bar, damage flash, fade-in end screen
- Singleton GameManager and a separate UIManager
- Procedurally generated sound effects (no audio files)
- Particle effects, camera follow and screen shake
- 2D lighting
- Main menu scene with saved high score (PlayerPrefs)

## Tech
Unity 6.3 LTS (6000.3.26f1), C#, Universal 2D Renderer, Input System, TextMeshPro

## Run it
1. Open the project in Unity 6.3 LTS.
2. Open `Assets/Scenes/MainMenu` and press Play.
